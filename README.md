# PI15000

从普通浮点除法一路推到 spigot 算法，最后得到一个能算任意位 π 的 C11 小程序。
配套视频：[两行代码计算 PI 后 15,000 位](https://www.bilibili.com/video/BV1Tu4y1h7Qc/)

## 文件

| 文件 | 内容 |
| --- | --- |
| `pi.c` | 正式实现，构建产物为 `pi` |
| `pi_golf.c` | 同一算法的两行高尔夫写法，固定输出 15000 位 |
| `demos/01_float.c` | 普通浮点除法的精度能到哪 |
| `demos/02_long_division.c` | 长除法：一个有理数近似保证 34 位 |
| `demos/03_half_pi.c` | 用十进制数组算 `pi / 2` 的 2800 位 |
| `demos/04_pi.c` | 把 `pi / 2` 乘 2，得到 pi 的 2800 位 |

`demos/` 里四个程序就是视频里的推导顺序，按编号读即可。

## 构建与测试

需要 C11 编译器和 GNU make；测试只需要 Python 3 标准库。
测试用 Chudnovsky 独立算一份参考值，逐字节比对输出。

```bash
make            # 编译全部程序
make test       # 约 3 秒
make test-slow  # 另加 54936 和 100000 位，约 20 秒
make clean
```

Windows 上用 `mingw32-make`。编译器默认 `gcc`，也可以 `make CC=clang`；
测试默认找 `python3`，找不到就用 `python`，也可以显式指定：`make test PYTHON=python3.12`。

构建开 `-Wall -Wextra -Wpedantic -Wconversion -Werror`，出任何警告都算失败。

## 用法

参数是小数点后的位数，省略时输出 15000 位。

```console
$ pi 5
3.14159
$ pi 0
3
$ pi 100000 > pi.txt
```

输出约定：

- 位数是**截断**而不是四舍五入，所以 `pi 1` 输出 `3.1`。
- `pi 0` 只有整数部分，不带小数点。
- 所有平台都输出 LF，重定向到文件的结果逐字节一致。
- 退出码：`0` 成功；`1` 计算失败、内存不足或写输出失败；`2` 参数不对。
- `--help`（或 `-h`）把用法写到 stdout 并退出 `0`；参数错误时用法写到 stderr。
- `pi_golf` 固定 15000 位，不带小数点、不带结尾换行。

## 算法

以 1e9 为基数，每 30 个级数项产出一组 9 位数字，平均每个数字 3.33 项。
余数数组随轮次从高位往低位收缩，时间 `O(n²)`、空间 `O(n)`。

每组算出来可能满 1e9，多出的那一位属于刚写下的前一组，必须回填进去；
少了这一步，几万位之后就会在某个位置差一位，随后整组变成 1e9 而无法用 9 位表示。

耗时（含输出，i3-12100F）：

| 位数 | Windows i686（gcc 4.9，`-O3`） | WSL x86-64（gcc 13，`-O2`） |
| --- | --- | --- |
| 15000 | 0.34 s | 0.18 s |
| 50000 | 3.7 s | 2.1 s |
| 100000 | 14.5 s | 8.2 s |

`O(n²)` 的脾气是位数翻倍时间涨四倍。要几十万位以上，得换 Chudnovsky 二分拆分
加大整数库，那是另一个算法，不在本仓库范围内。
